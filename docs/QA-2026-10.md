## Summary

Every automated row is done; 5 rows wait on the owner's visual pass. **17 findings: 3 High, 4 Medium, 10 Low** (QA-17 found after the walkthrough, while verifying the QA-06/QA-14 fix). Nothing breaks login, generation, or data isolation; the core RAG loop, all four generation modes, History, and templates work end to end against live models.

**Fix first (High):**
- **QA-06 + QA-14, one root cause:** card export depends on the brand font existing on the fontsource CDN. A new workspace (no fonts) and any workspace that used "Learn from an image" end up with a font the CDN doesn't have, and Export PNG stays disabled with no message. Fixing the export to fall back to a bundled font, and making extract map onto the curated list, closes both (PR #58).
- **QA-17:** exported cards show a "NO GLYPH" box for subscript digits (CO₂), which the card fonts' Latin subsets don't include. Fixed with glyph fallbacks (PR #59).

**Then (Medium):** QA-02 (half-signed-in session after an early reload, fixed in PR #62), QA-03 (ingestion errors always generic, fixed in PR #60), QA-07 (Remove image doesn't persist, fixed in PR #63), QA-12 (template upload errors always generic, fixed in PR #60).

**Pattern worth one shared fix:** QA-03, QA-12, and QA-15 are the same bug in three places: the server sends a specific reason and the client shows a generic message. Fixed together in PR #60 (`apiErrorMessage`).

**Low:** copy and prompts (QA-01, 05, 08, 09, 11) fixed in PR #64, with the client UI copy cleared of em dashes; UI and a11y (QA-04, 10, 13, 16) fixed in PR #65, where the new shared confirm also covers template and History generation deletes.

**Known gaps (not findings), since closed:** the demo daily quota didn't count the AI routes that persist nothing (brand extract, template AI fill, fill-from-document), fixed by one AI-call counter in PR #67 (DECISIONS #35); there was no Content Security Policy, fixed in PR #68 (DECISIONS #36). Planning them also found the production image served a blank page (fixed in PR #66), and settings secrets that could print in tracebacks (fixed in PR #69, DECISIONS #37). Per-IP rate limits behind a load balancer (R2) and HSTS at the edge stay deploy items.

## Method

Two tracks run in parallel:

1. **Browser walkthrough (hybrid).** Claude drives the flows below with Playwright (screenshots, network and console capture, downloaded files inspected). Rows marked **Owner** need a human eye: rendering fidelity, fonts, layout feel. They're batched for one short visual pass at the end.
2. **Regression code review.** A read of `git diff 6b7f1d0 dev` (the pre-audit base to now), looking only for behavior that changed by accident in the refactors: ARCH-01 uploads, ARCH-02 SSE, ARCH-04 generation hooks, ARCH-05 caps, ARCH-06 file splits, STYLE-01, and the B1/B2 security changes.

**Severity:** **High** breaks a user flow or loses data. **Medium** is wrong behavior in a reachable case. **Low** is cosmetic or an edge case.

**Result key:** ✅ pass · ❌ fail (see finding) · ⚠️ works, but noted · ⏭️ skipped (with reason)
